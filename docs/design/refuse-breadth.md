# Refuse breadth that does not raise finish rate

**Status:** Active product policy (2026-08)  
**Related:** `discovery-workbench-v3.md`, north-star loop

## Rule

Do **not** add another free public API panel, regulator surface, or literature source unless it is expected to raise at least one of:

1. **M1** completed loop rate (discover → board → pack/RH) on golden paths  
2. **M3** median citable claims on pack export (≥5 soft target)  
3. **Shortlist trust** (honest empty/timeout, not silent blanks)

## Preferred work instead

- Finish-rate strip + funnel measurement  
- One-click golden paths / campaign spine  
- Pack → Monday handoff  
- Soft-empty / partial-timeout honesty  
- Share + IDB rehydrate reliability  

## Explicit non-goals

- Paid DBs  
- LLM of-record rank  
- Regulatory decision support language  
- Multi-tenant cloud as loop default
